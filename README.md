# Store Name - Bootcamp Hackathon
¡Bienvenidos al repositorio del equipo 2, de CH62! Este proyecto fue desarrollado durante una hackatón de práctica como parte del bootcamp Ch62. El objetivo principal fue construir una tienda funcional en un tiempo récord, poniendo a prueba nuestras habilidades de colaboración y desarrollo técnico.

## Sobre el Proyecto
Esta aplicación es una plataforma de e-commerce que permite a los usuarios navegar por productos, ver detalles específicos de cada artículo y gestionar un carrito de compras de manera dinámica.

El enfoque principal fue crear una experiencia de usuario (UX) fluida, asegurando que el flujo desde el catálogo hasta la intención de compra sea intuitivo y rápido.

Duración: 7 horas.

Reto: Crear una landin page responsiva.
